preservar um endereço compartilhado mesmo quando o convite de destino expirar.

Contrato a entregar: POST /api/v1/me/redirects; POST /me/redirects/:id/destinations; GET /api/v1/r/:handle resolve; rota web /r/:handle.

Dados: RedirectHandle estável e DestinationRevision aprovada; usuário altera revisão, nunca identidade pública; vínculo opcional a ProfileItem; histórico de destino separado das métricas.
